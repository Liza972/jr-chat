# Онлайн Чат

Веб-приложение для обмена сообщениями в реальном времени с использованием современного стека технологий.

## Особенности

- 🚀 Real-time обновление сообщений каждые 3 секунды
- 💬 Поддержка смайликов (:) → 😊, :( → 😞, и т.д.)
- 💻 Форматирование кода (inline и блоки кода)
- 👤 Сохранение имени пользователя в localStorage
- 📱 Адаптивный дизайн для всех устройств
- 🔒 Валидация данных на клиенте и сервере
- 🐳 Полная контейнеризация с Docker Compose
- 📊 Статистика чата в реальном времени

## Технологии

### Backend
- Node.js с TypeScript
- Express.js для REST API
- Встроенная валидация и rate limiting
- Хранение сообщений в памяти

### Frontend
- HTML5, CSS3, Vanilla JavaScript
- Адаптивный дизайн с Flexbox/Grid
- Font Awesome и Google Fonts
- Nginx для раздачи статики и проксирования

### Инфраструктура
- Docker для контейнеризации
- Docker Compose для оркестрации
- Nginx как reverse proxy
